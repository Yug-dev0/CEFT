# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3.0 | :x:                |

## Reporting a Vulnerability

Security issues are taken very seriously. If you discover a security vulnerability in Ceft, please report it privately:

- **Contact**: Yug Patel
- **Email**: [yug.dev04@gmail.com](mailto:yug.dev04@gmail.com)
- **Subject**: `[SECURITY VULNERABILITY] Ceft`

Please include:
1. A description of the issue and potential impact.
2. Steps or proof-of-concept scripts to reproduce the vulnerability.
3. Any mitigations or fixes you recommend.

You should receive an acknowledgment within 48 hours. Please do not report security vulnerabilities via public GitHub issues.
